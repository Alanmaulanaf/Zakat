# Non-Functional Requirements

## Security

### NFR-001 — Authentication

Pengguna harus melakukan autentikasi sebelum menggunakan
fitur yang membutuhkan hak akses.

### NFR-002 — Authorization

Sistem harus membatasi akses berdasarkan role dan lokasi
pengguna.

### NFR-003 — Password Security

Password tidak boleh disimpan dalam bentuk plaintext.

### NFR-004 — HTTPS

Komunikasi antara aplikasi dan server harus menggunakan HTTPS.

---

## Usability

### NFR-014 — Usability

Antarmuka harus sederhana dan mudah digunakan oleh
petugas yang tidak memiliki latar belakang teknologi.

---

## Maintainability

### NFR-010 — Maintainability

Kode sistem harus dibuat secara modular sehingga
perubahan pada satu bagian tidak menyebabkan perubahan
besar pada bagian lain.
