# Functional Requirements

## Authentication

### FR-001 — Login

Sistem harus memungkinkan pengguna yang telah terdaftar
untuk melakukan login.

### FR-002 — Logout

Sistem harus memungkinkan pengguna keluar dari sistem.

---

## User Management

### FR-003 — Manajemen Pengguna

Admin Desa harus dapat mengelola akun pengguna.

Data pengguna minimal:

- Nama
- Username/email
- Role
- Lokasi
- Status akun

### FR-004 — Role Pengguna

Sistem harus menerapkan hak akses berdasarkan role.

Role V1:

- Admin Desa
- Petugas Lokasi
- DKM

---

## Lokasi

### FR-005 — Kelola Lokasi

Admin Desa harus dapat menambahkan, melihat, mengubah,
dan menonaktifkan lokasi pembayaran zakat.

Jenis lokasi:

- Masjid
- Musholla
- SD
- TK
