# Project Overview

## Nama Project

Sistem Pendataan dan Rekapitulasi Zakat Fitrah Desa

## Latar Belakang

Proses pendataan zakat fitrah di desa saat ini dilakukan
secara manual pada beberapa lokasi pembayaran seperti
masjid, musholla, SD, dan TK.

Petugas mencatat pembayaran zakat pada formulir/kertas.
Beberapa hari sebelum Idul Fitri, data dari masing-masing
lokasi dikumpulkan ke pemerintah desa.

Pemerintah desa kemudian melakukan rekapitulasi kembali,
yang saat ini dilakukan menggunakan Excel.

Proses tersebut menyebabkan adanya pencatatan ulang dan
berpotensi menimbulkan kesalahan dalam proses rekapitulasi.

## Tujuan

Membangun sistem digital yang membantu proses:

- Pendataan zakat fitrah
- Pengelolaan data zakat
- Rekapitulasi per lokasi
- Rekapitulasi tingkat desa
- Pelaporan zakat fitrah

## Pengguna Sistem

- Petugas Lokasi
- Admin Desa
- DKM

Warga tidak menjadi pengguna langsung aplikasi pada V1.
Warga melakukan pembayaran kepada petugas dan petugas
yang melakukan pencatatan pada sistem.
